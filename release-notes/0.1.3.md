### What's changed
- Update notices now remember when you've acted on a release, so the same version won't keep appearing. A newer release will still be announced.
- On iPhone and iPad, choosing either alert action acknowledges that release. On Mac, Sparkle remembers your choice.

### macOS build
Apple Silicon (arm64). The app is ad-hoc signed and the build is not notarized, so macOS may block the first launch.

### Opening RED Bit on macOS
Only continue if you downloaded this DMG from the official RED Bit release and trust it.

**System Settings:** Move RED Bit to Applications and try to open it once. If macOS blocks it, open System Settings → Privacy & Security, scroll to Security, choose **Open Anyway** for RED Bit, then confirm **Open** in the warning dialog.

**Terminal:** After moving RED Bit to Applications, open Terminal and run:
```sh
xattr -dr com.apple.quarantine "/Applications/RED Bit.app"
open "/Applications/RED Bit.app"
```
This removes the downloaded-file quarantine attribute from the app bundle so Gatekeeper no longer blocks this launch.
