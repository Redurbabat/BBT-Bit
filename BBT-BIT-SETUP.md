# BBT-Bit

Dieses Repository ist für die neue Musik-App BBT-Bit vorgesehen. Es übernimmt den quelloffenen Code von [RED Bit](https://github.com/Redurbabat/RED-Bit).

## Herkunft und Lizenz

RED Bit ist ein eigenständiges Open-Source-Projekt. Beim Import bleiben der ursprüngliche Quellcode, die Lizenzdateien (`LICENSE`, `LICENSES`) und `THIRD_PARTY_NOTICES.md` erhalten. Weitere Lizenzpflichten gelten je nach enthaltenem Modul. BBT-Bit ist nicht offiziell mit RED Bit, YouTube oder Google verbunden.

## Import und Status

Der Import erfolgt über einen gesonderten Git-Zweig, damit alle Dateien vor der Übernahme geprüft werden können. Die native iOS-App benötigt für den Build Xcode, Rust und weitere Abhängigkeiten sowie eine gültige iOS-Signatur für die Installation.
